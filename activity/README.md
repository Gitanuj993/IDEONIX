# Activity sections !

**This section will tell us what we do and what we did**
## Structure of this section
1. a file named with date should be placed in this section.
2. on next day the file will be transferred into respective month or year directory.


## What we write in this file ?
1. Tasks and goals for the day.
2. Daily activity log.
3. That day's objective and conclusions.


## Who is responsible for its management and correctness on daily basis?
1. A dedicated team member will be appointed.
2. information present in it can be changed and modified by any member after approval.
